图3-1 系统总体架构图

基于真实源码绘制，系统由感知与执行层、嵌入式控制层、通信与接入层、管理与存储层、展示与交互层构成， 不包含独立后端服务。 

flowchart TB
    subgraph L1["感知与执行层"]
        direction LR
        S1["环境传感器<br/>DHT11 / MQ-135 / GP2Y10"]
        S2["资源传感器<br/>ACS712 / 水流传感器"]
        A1["执行与本地显示<br/>风扇 / 舵机 / 蜂鸣器 / 三色灯 / OLED"]
    end

    subgraph L2["嵌入式控制层"]
        direction TB
        STM32["STM32F103 主控制器<br/>数据采集 / 阈值判断 / 三级预警 / 组合联动 / JSON打包"]
    end

    subgraph L3["通信与接入层"]
        direction TB
        ESP32["ESP32 通信网关<br/>UART缓存 / WiFi接入 / MQTT发布订阅 / 命令转发 / 防回环"]
        MQTT["MQTT 消息服务<br/>主题: test001up / WebQT1"]
    end

    subgraph L4["管理与存储层"]
        direction LR
        QT["Qt 桌面管理端<br/>实时监测 / 阈值设置 / 远程控制 / 报警管理 / 历史查询 / 用户认证"]
        DB["SQLite 本地数据库<br/>data / alarm_info / remote_exec_logs / device_info / users"]
    end

    subgraph L5["展示与交互层"]
        direction LR
        WEB["Web 看板<br/>实时展示 / 历史趋势 / 一键求助"]
        USER["管理人员与安置点用户"]
    end

    S1 -- "监测数据" --> STM32
    S2 -- "资源数据" --> STM32
    STM32 -- "控制输出" --> A1
    A1 -. "状态反馈" .-> STM32

    STM32 <-->|USART1 串口| ESP32
    ESP32 <-->|MQTT 消息| MQTT

    MQTT -- "实时数据" --> QT
    QT -- "阈值与控制命令" --> MQTT
    MQTT -- "实时展示数据" --> WEB
    WEB -- "一键求助消息" --> MQTT

    QT <--> DB

    QT --> USER
    WEB --> USER

    N1["无独立后端服务<br/>业务管理与数据持久化由 Qt + SQLite 本地完成"]
    L4 --- N1
